## Your first steps

1. Unzip the bundle into the Moya One repo folder, or into a new folder if the repo isn't set up yet.
2. Open a Claude Code session in that folder.
3. Paste the contents of PASTE_INTO_CLAUDE_CODE.md.
4. Answer Claude Code's questions. Send any open questions to Vinayak on WhatsApp.
5. Start with the jug illustration, then Phase 1 Must pages in the order given in DEVELOPER_PROMPT.md.

## Approval rules (important)

- **Every design you make goes to Vinayak on WhatsApp before it is treated as final.** Send screenshots at 390px and 1440px. Wait for approval.
- **Nothing goes to the client directly.** Vinayak is your contact for approvals and questions. If the client writes to you, reply that you'll pass it to Vinayak.
- **Claims are checked first.** Only publish claims marked OK or Verified in the Claims tab of the tracker.
- **Scope changes go to Vinayak.** If the client asks for a new page, a new feature or a new video, don't start it. Note it in the tracker and send it to Vinayak.

## Hard rules

- No prices or rupee/dirham figures on the site in phase 1.
- No patent or technology detail. Say "patent filed", not "patented".
- Deployments: India only, marked "to confirm". No UAE developer names or logos.
- Every number is labelled "Sample data" or "Illustrative".
- Run the design audit (CLAUDE.md, section "Design audit") after every change, using the design-taste-frontend skill and the impeccable skill.

## Open questions you'll hit early

These are waiting on the client. Don't build the final version of these parts until they are answered:

- Final brand spelling: Moya One, MoyaOne, MoyàOne, or Moya1. Use placeholder text until confirmed.
- Logo: the client's variations are AI-generated, so Vinayak is rebuilding them in Figma. Use the Figma file once it's shared.
- Which Hyderabad projects can be named on the site.
- Whether competitor brand names can appear in comparisons.
- Zero water wastage and 3LD claims: unverified.
